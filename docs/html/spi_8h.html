◆ SPI_SSIG_BIT

#define SPI_SSIG_BIT   7

SPCTL register SSIG (SS ignore) bit position.

If SSIG=1, MSTR decides whether the device is a master or a slave. If SSIG=0, the SS pin decides it. Note that if SSIG=1, CPHA must not be 0, otherwise the operation is undefined.
